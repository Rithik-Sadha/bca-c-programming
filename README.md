# bca-c-programming
Documenting my daily c programming practice, logic building, and BCA coursework.

## Day 1 Topics Covered
- Basic console output (`printf`)
- Taking user input (`scanf` & pointers)
- Arithmetic calculations (division, multiplication)
- Conditional logic (`if` / `else`)

## Day 2 Topics Covered
- Multiple conditions using `else if`
- Range-based logical evaluation

## Files
- `first_step.c` - Basic program structure
- `day1_input.c` - Interactive user input
- `day1_calc.c` - Daily earning calculations
- `day1_conditions.c` - Goal tracking logic
- `daily-tracker.c` - Daily target vs actual earning tracker
- `attendance_checker.c` - Student exam eligibility calculator
- `grade_calculator.c` - Student grade evaluation based on score tiers
- `speed_limit.c` - Speed monitor with multi-tiered traffic alerts
